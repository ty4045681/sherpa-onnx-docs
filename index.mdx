## 快速上手流程

<Steps>
  <Step title="安装 sherpa-onnx">
    根据您的开发语言选择对应的安装方式，例如 Python 使用 `pip install sherpa-onnx`
  </Step>
  <Step title="下载预训练模型">
    从 [GitHub Releases](https://github.com/k2-fsa/sherpa-onnx/releases/tag/kws-models) 下载中文或英文 KWS 模型包
  </Step>
  <Step title="编写关键词文件">
    创建 `keywords.txt`，每行一个关键词，按照拼音或 BPE 格式填写词元
  </Step>
  <Step title="运行关键词唤醒">
    调用 `KeywordSpotter` API，实时检测音频流中的关键词
  </Step>
</Steps>
