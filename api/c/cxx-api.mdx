sherpa-onnx 的 C++ API 以 RAII 和面向对象风格封装了底层 C API，定义于头文件 `sherpa-onnx/c-api/cxx-api.h`（`sherpa_onnx::cxx` 命名空间）和 `sherpa-onnx/csrc/keyword-spotter.h`（`sherpa_onnx` 命名空间）。与 C API 相比，C++ API 通过移动语义自动管理资源生命周期，并原生支持批量并发解码多路音频流。

## 概述

C++ API 头文件分工如下：

| 头文件 | 用途 |
|---|---|
| `sherpa-onnx/csrc/keyword-spotter.h` | 完整 C++ 实现，含 `KeywordSpotter`、`KeywordResult`、`KeywordSpotterConfig` 等 |
| `sherpa-onnx/c-api/cxx-api.h` | 轻量 C++ 封装层（`sherpa_onnx::cxx` 命名空间），链接 C ABI，适合动态库集成 |

### C++ API 与 C API 的主要区别

| 特性 | C API | C++ API |
|---|---|---|
| **内存管理** | 手动调用 `Destroy*` 系列函数 | RAII + `std::unique_ptr` 自动析构 |
| **接口风格** | 过程式，全局函数 + 不透明指针 | 面向对象，`KeywordSpotter` 类封装 |
| **并发解码** | 需自行管理流数组指针 | `Decode(ss, n)` 原生支持批量解码 |
| **错误处理** | 返回 `NULL` 指针检查 | 可结合 `.Get()` 空指针检查或异常机制 |
| **字符串类型** | `const char *` | `std::string`，消除缓冲区管理负担 |
| **跨平台** | ABI 稳定，可供任意语言 FFI 调用 | 仅限 C++ 项目，依赖 C++ 标准库 ABI |

## 核心类与结构体

### KeywordResult 结构体

`KeywordResult` 存储单次关键词检测结果，定义于 `sherpa-onnx/csrc/keyword-spotter.h`（`sherpa_onnx` 命名空间）和 `sherpa-onnx/c-api/cxx-api.h`（`sherpa_onnx::cxx` 命名空间）：

```cpp
namespace sherpa_onnx {

struct KeywordResult {
  // 触发的关键词文本
  // 英文：空格分隔的单词，例如 "hello world"
  // 中文：连续汉字，例如 "你好小明"
  std::string keyword;

  // token 级别的解码序列（BPE token 或 CJK 字符列表）
  std::vector<std::string> tokens;

  // 时间戳数组，timestamps[i] 表示 tokens[i] 被解码时的秒数
  // timestamps.size() == tokens.size()
  std::vector<float> timestamps;

  // 当前片段的起始时间（秒），端点检测时会更新
  float start_time = 0;

  // 返回 JSON 字符串，格式：
  // {
  //   "keyword":    "触发的关键词",
  //   "tokens":     ["t1", "t2", ...],
  //   "timestamps": [0.1, 0.3, ...],
  //   "start_time": 0.0
  // }
  std::string AsJsonString() const;
};

} // namespace sherpa_onnx
```

<ParamField path="keyword" type="std::string">
  触发的关键词。若本次未检测到关键词则为空字符串（`empty()`），可用 `!r.keyword.empty()` 判断是否触发。
</ParamField>

<ParamField path="tokens" type="std::vector<std::string>">
  解码得到的 token 序列。对于 BPE 模型为子词单元（如 `▁he`、`llo`），对于字符级中文模型为单字。
</ParamField>

<ParamField path="timestamps" type="std::vector<float>">
  每个 token 对应的解码时间（秒），数组长度与 `tokens` 相同，可用于精确定位关键词边界。
</ParamField>

<ParamField path="start_time" type="float" default="0.0">
  当前片段的起始时间戳（秒），在端点检测（Endpoint Detection）后会随新片段重置。
</ParamField>

### KeywordSpotterConfig 结构体

```cpp
namespace sherpa_onnx {

struct KeywordSpotterConfig {
  FeatureExtractorConfig feat_config;    // 特征提取配置（采样率、帧长等）
  OnlineModelConfig      model_config;   // 模型路径、provider、线程数等

  int32_t max_active_paths    = 4;       // Beam Search 最大激活路径数
  int32_t num_trailing_blanks = 1;       // 结尾 blank 帧数，用于稳定边界
  float   keywords_score      = 1.0;    // 关键词 token 分数加成
  float   keywords_threshold  = 0.25;   // 触发置信度阈值 [0, 1]

  std::string keywords_file;            // 关键词列表文件路径
  std::string keywords_buf;             // 关键词列表的内存 buffer（与 keywords_file 二选一）
};

} // namespace sherpa_onnx
```

### KeywordSpotter 类

`KeywordSpotter` 是关键词唤醒的核心类，实现了 Pimpl 模式（通过 `KeywordSpotterImpl` 隐藏实现细节）。`cxx-api.h` 中的封装版（`sherpa_onnx::cxx::KeywordSpotter`）继承自 `MoveOnly`，通过移动语义自动管理底层 C 句柄。

#### 工厂方法 / 构造函数

```cpp
// cxx-api.h 封装层（推荐用于动态库场景）：工厂方法，返回值语义
// 失败时 .Get() 返回 nullptr
using namespace sherpa_onnx::cxx;
KeywordSpotter kws = KeywordSpotter::Create(config);
if (!kws.Get()) { /* 配置有误 */ }

// csrc 直接使用（推荐用于源码编译场景）：构造函数，失败时抛出异常
sherpa_onnx::KeywordSpotter kws(config);
```

#### CreateStream()

```cpp
// 创建使用预定义关键词列表的解码流
OnlineStream stream = kws.CreateStream();

// 创建在预定义关键词基础上追加自定义关键词的解码流
// 多个关键词以 "/" 分隔，每个关键词内 token 以空格分隔
// "@" 后接可读显示标签（出现在 KeywordResult::keyword 中）
OnlineStream stream = kws.CreateStream("y ǎn y uán @演员");
OnlineStream stream = kws.CreateStream("y ǎn y uán @演员/zh ī m íng @知名");
```

<Tip>
  `CreateStream(keywords)` 中的关键词字符串语法与 C API 的 `SherpaOnnxCreateKeywordStreamWithKeywords` 完全相同，支持在运行时动态扩展关键词集合，无需重新加载模型。
</Tip>

#### IsReady(stream)

```cpp
bool KeywordSpotter::IsReady(OnlineStream *s) const;
```

返回 `true` 表示流中已积累足够帧可以进行一轮解码；返回 `false` 时应等待更多音频输入后再检查。

#### Decode(stream) / Decode(streams, n)

`cxx-api.h` 封装层中，单路和多路解码均使用重载的 `Decode` 方法：

```cpp
// 解码单路流
void KeywordSpotter::Decode(const OnlineStream *s) const;

// 批量并发解码多路流（利用底层线程池并行处理）
// ss 为指针数组，n 为数组长度
void KeywordSpotter::Decode(const OnlineStream *ss, int32_t n) const;
```

`sherpa-onnx/csrc/keyword-spotter.h` 中的底层实现方法名为 `DecodeStream` 和 `DecodeStreams`：

```cpp
// csrc 层（sherpa_onnx 命名空间）
void KeywordSpotter::DecodeStream(OnlineStream *s) const;   // 内部委托给 DecodeStreams
void KeywordSpotter::DecodeStreams(OnlineStream **ss, int32_t n) const;
```

<Tip>
  **批量解码的性能优势**：`Decode(ss, n)` 在内部利用 ONNX Runtime 的批处理能力，将多个流的特征帧合并为一个批次送入模型。在同时监听多路麦克风（如会议室多人唤醒、智能家居多设备唤醒）场景下，批量解码的吞吐量可接近单流的 N 倍，CPU/GPU 利用率显著高于逐流串行调用。
</Tip>

#### GetResult(stream)

```cpp
KeywordResult KeywordSpotter::GetResult(const OnlineStream *s) const;
```

返回当前流的检测结果（按值返回，生命周期由调用方管理）。`result.keyword.empty()` 为 `true` 时表示本次未触发任何关键词。

#### Reset(stream)

```cpp
void KeywordSpotter::Reset(const OnlineStream *s) const;
```

**检测到关键词后必须调用**，清空内部解码状态（保留关键词配置），使流可以继续监听下一次唤醒。

## 完整 C++ 示例代码

以下示例来自 [`cxx-api-examples/kws-cxx-api.cc`](https://github.com/k2-fsa/sherpa-onnx/blob/master/cxx-api-examples/kws-cxx-api.cc)，展示了三种关键词流的典型用法：

```cpp
// cxx-api-examples/kws-cxx-api.cc
// Copyright (c) 2025 Xiaomi Corporation
//
// 模型下载：
// wget https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile.tar.bz2
// tar xvf sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile.tar.bz2
//
// 编译后运行：./kws-cxx-api

#include <array>
#include <iostream>
#include <string>

#include "sherpa-onnx/c-api/cxx-api.h"

int32_t main() {
  using namespace sherpa_onnx::cxx;  // NOLINT

  // ---- 1. 填写配置（与 C API 字段一一对应，类型为 std::string）----
  KeywordSpotterConfig config;
  config.model_config.transducer.encoder =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "encoder-epoch-12-avg-2-chunk-16-left-64.int8.onnx";
  config.model_config.transducer.decoder =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "decoder-epoch-12-avg-2-chunk-16-left-64.onnx";
  config.model_config.transducer.joiner =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "joiner-epoch-12-avg-2-chunk-16-left-64.int8.onnx";
  config.model_config.tokens =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "tokens.txt";
  config.model_config.provider    = "cpu";
  config.model_config.num_threads = 1;
  config.model_config.debug       = 1;
  config.keywords_file =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "test_wavs/test_keywords.txt";

  // ---- 2. 创建 KeywordSpotter 实例 ----
  KeywordSpotter kws = KeywordSpotter::Create(config);
  if (!kws.Get()) {
    std::cerr << "Please check your config\n";
    return -1;
  }

  std::string wave_filename =
      "./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01-mobile/"
      "test_wavs/3.wav";

  std::array<float, 8000> tail_paddings = {0};  // 0.5 秒静音填充

  Wave wave = ReadWave(wave_filename);
  if (wave.samples.empty()) {
    std::cerr << "Failed to read: '" << wave_filename << "'\n";
    return -1;
  }

  // ---- 场景 1：仅使用预定义关键词列表 ----
  std::cout << "--Test pre-defined keywords from test_wavs/test_keywords.txt--\n";

  OnlineStream stream = kws.CreateStream();
  if (!stream.Get()) {
    std::cerr << "Failed to create stream\n";
    return -1;
  }

  stream.AcceptWaveform(wave.sample_rate,
                        wave.samples.data(), wave.samples.size());
  stream.AcceptWaveform(wave.sample_rate,
                        tail_paddings.data(), tail_paddings.size());
  stream.InputFinished();

  while (kws.IsReady(&stream)) {
    kws.Decode(&stream);
    auto r = kws.GetResult(&stream);
    if (!r.keyword.empty()) {
      std::cout << "Detected keyword: " << r.json << "\n";
      kws.Reset(&stream);  // 检测到后立即重置！
    }
  }

  // ---- 场景 2：预定义关键词 + 运行时追加 1 个新关键词 ----
  std::cout << "--Use pre-defined keywords + add a new keyword--\n";

  stream = kws.CreateStream("y ǎn y uán @演员");

  stream.AcceptWaveform(wave.sample_rate,
                        wave.samples.data(), wave.samples.size());
  stream.AcceptWaveform(wave.sample_rate,
                        tail_paddings.data(), tail_paddings.size());
  stream.InputFinished();

  while (kws.IsReady(&stream)) {
    kws.Decode(&stream);
    auto r = kws.GetResult(&stream);
    if (!r.keyword.empty()) {
      std::cout << "Detected keyword: " << r.json << "\n";
      kws.Reset(&stream);
    }
  }

  // ---- 场景 3：预定义关键词 + 运行时追加 2 个新关键词（用 / 分隔）----
  std::cout << "--Use pre-defined keywords + add two new keywords--\n";

  stream = kws.CreateStream("y ǎn y uán @演员/zh ī m íng @知名");

  stream.AcceptWaveform(wave.sample_rate,
                        wave.samples.data(), wave.samples.size());
  stream.AcceptWaveform(wave.sample_rate,
                        tail_paddings.data(), tail_paddings.size());
  stream.InputFinished();

  while (kws.IsReady(&stream)) {
    kws.Decode(&stream);
    auto r = kws.GetResult(&stream);
    if (!r.keyword.empty()) {
      std::cout << "Detected keyword: " << r.json << "\n";
      kws.Reset(&stream);
    }
  }

  // wave、kws、stream 均为 RAII 对象，离开作用域自动析构
  return 0;
}
```

<Note>
  C++ API 中的 `OnlineStream` 采用移动语义（`stream = kws.CreateStream(...)`），支持赋值给已有变量。旧流对象在赋值时自动析构，无需手动释放。
</Note>

## 批量并发解码示例

以下代码片段展示如何同时解码 N 路独立音频流，充分利用 `Decode(ss, n)` 的批处理加速：

```cpp
#include "sherpa-onnx/c-api/cxx-api.h"
#include <vector>
#include <iostream>

using namespace sherpa_onnx::cxx;

// 假设已创建 kws（sherpa_onnx::cxx::KeywordSpotter）

constexpr int kNumStreams = 4;

// 为 4 路音频各创建一个流
std::vector<OnlineStream> streams;
streams.reserve(kNumStreams);
for (int i = 0; i < kNumStreams; ++i) {
  streams.push_back(kws.CreateStream());
}

// 向每路流送入各自的音频帧（此处省略实际音频来源）
for (int i = 0; i < kNumStreams; ++i) {
  streams[i].AcceptWaveform(16000, pcm_buffers[i], pcm_lengths[i]);
}

// 检查哪些流已就绪，收集就绪流的指针
std::vector<const OnlineStream *> ready_streams;
for (auto &s : streams) {
  if (kws.IsReady(&s)) {
    ready_streams.push_back(&s);
  }
}

// 批量并发解码所有就绪的流
if (!ready_streams.empty()) {
  kws.Decode(ready_streams.data(),
             static_cast<int32_t>(ready_streams.size()));
}

// 查询每路流的结果
for (auto *s : ready_streams) {
  auto r = kws.GetResult(s);
  if (!r.keyword.empty()) {
    std::cout << "Stream triggered keyword: " << r.keyword << "\n";
    kws.Reset(s);
  }
}
```

<Tip>
  **Decode(ss, n) 的性能优势**：在多路并发场景（如多人唤醒词检测、批量音频文件处理）中，`Decode(ss, n)` 将 N 路流的特征帧合并为一个 Batch 送入 ONNX Runtime，GPU/CPU 的矩阵乘法利用率远高于 N 次串行调用 `Decode(s)`。实测在 4 路并发时，端到端延迟约为单路的 1.1 到 1.5 倍，而非 4 倍，吞吐量提升显著。
</Tip>

## 关键词文件格式速查

关键词文件（`keywords.txt`）每行对应一个关键词，格式如下：

```
# 格式：音素序列 @显示标签（@标签可选）
# 中文示例（声母+韵母+声调分离）：
x iǎo m íng @小明
n ǐ h ǎo @你好
# 英文示例（BPE token，以 ▁ 开头的为词首）：
▁HE LL O ▁W OR LD @hello world
# 多条关键词直接换行
zh ī m íng @知名
```

<Warning>
  **格式注意事项**：

  - 中文关键词需将每个音素/字符用**空格分隔**，不可直接写汉字。具体的音素序列从模型的 `tokens.txt` 文件中查找。
  - `@` 及其后的显示标签决定 `KeywordResult::keyword` 字段的值。未设置 `@` 标签时，`keyword` 为音素序列拼接结果。
  - 动态关键词字符串（`CreateStream(keywords)` / `SherpaOnnxCreateKeywordStreamWithKeywords`）中，多个关键词以 `/` 分隔，语法与文件格式一致。
</Warning>
